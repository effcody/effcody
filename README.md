## About me

Hey, I'm Cody, a developer from Delhi, India. I build Discord bots and the backend that keeps them running. I enjoy the parts of software people rarely see: uptime, queues, clean data, and making sure everything still works when a server gets busy.

**[Kira](https://top.gg/bot/1530820286830743744/vote)** is my main project, a Lavalink-powered Discord music bot. **[Kira Development](https://www.kiramusic.bond/)** is the studio and community around it, where I build, learn, and work with other developers.

```text
based in       ->   Delhi, India
main project   ->   Kira, a Lavalink-powered Discord music bot
daily stack    ->   TypeScript, Node.js, Python
learning       ->   Java (Spring Boot) and Rust
```

## What I'm working on

| Project | What it is |

| Kira Development | The studio and community behind Kira, focused on building and learning together |

| Learning builds | Practice projects in Java and Rust while I level up beyond Node.js |

## Featured project

### Kira - Discord music platform

Kira brings music to Discord servers with smooth playback, queue management, audio filters, and server-level controls. It is built for real communities, so stability and a simple experience come before extra features.
